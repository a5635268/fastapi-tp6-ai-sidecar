# 双 Token 刷新机制与 Auth 接口使用说明

本文档介绍如何在业务开发中配置、测试及在前端客户端中对接 FastAPI Enterprise 的双 Token 刷新与认证接口。

---

## 1. 环境配置说明

在项目 `.env` 文件中配置以下 JWT 与 RSA 参数：

```ini
# JWT 密钥与算法配置
JWT_SECRET="your-secret-key-change-in-production"
JWT_ALGORITHM=HS256

# Access Token 过期时间（分钟），推荐 15-30 分钟
ACCESS_TOKEN_EXPIRE_MINUTES=30

# Refresh Token 过期时间（天），推荐 7-14 天
REFRESH_TOKEN_EXPIRE_DAYS=7

# RSA 私钥文件路径（相对路径固定以项目根目录为基准）
RSA_PRIVATE_KEY_PATH=data/keys/rsa_private_key.pem
```

## 2. API 接口清单

| 接口方法 | 路由路径 | 说明 | Header 依赖 | 请求体 | 响应示例数据 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/auth/rsa-key` | 获取服务端 RSA 公钥 | 无 | 无 | `{ "public_key": "-----BEGIN PUBLIC KEY..." }` |
| `POST` | `/api/v1/auth/login` | 用户登录并获取双 Token | `User-Agent` | `LoginRequest` | `{ "access_token": "...", "refresh_token": "...", ... }` |
| `POST` | `/api/v1/auth/refresh` | 轮换刷新 Token 对 | `User-Agent` | `RefreshTokenRequest` | `{ "access_token": "...", "refresh_token": "...", ... }` |
| `POST` | `/api/v1/auth/logout` | 登出并作废 Token | `Authorization: Bearer <token>` | `LogoutRequest` | `{ "success": true }` |
| `GET` | `/api/v1/auth/me` | 获取当前登录用户信息 | `Authorization: Bearer <token>` | 无 | `{ "id": 1, "username": "user_1", ... }` |

## 3. 前端/客户端对接指南

### 3.1 核心流程概览
1. **登录**：调用 `POST /api/v1/auth/login`，在内存（如 Pinia / Vuex / Redux）中保存 `access_token`，在 `localStorage` 或 安全 Cookie 中保存 `refresh_token`。
2. **API 请求**：所有业务接口在请求头附加 `Authorization: Bearer <access_token>`。
3. **401 无感续期**：当 API 返回 401 且错误原因非登录凭证无效时，拦截器自动挂起当前失败请求，调用 `POST /api/v1/auth/refresh` 传入 `refresh_token`。
4. **重试**：续期成功后更新本地双 Token，并用新的 `access_token` 自动重试先前挂起的请求。

### 3.2 Axios 拦截器参考实现 (JavaScript/TypeScript)

```typescript
import axios from 'axios';

const api = axios.create({
  baseURL: '/api/v1',
});

let isRefreshing = false;
let failedQueue: Array<{ resolve: (token: string) => void; reject: (err: any) => void }> = [];

const processQueue = (error: any, token: string | null = null) => {
  failedQueue.forEach((prom) => {
    if (error) {
      prom.reject(error);
    } else {
      prom.resolve(token!);
    }
  });
  failedQueue = [];
};

// 请求拦截器：自动注入 Access Token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器：自动捕获 401 并发起无感刷新
api.interceptors.response.use(
  (response) => response,
  async (error) => {
    const originalRequest = error.config;

    if (error.response?.status === 401 && !originalRequest._retry) {
      if (originalRequest.url?.includes('/auth/refresh')) {
        // 如果是刷新接口自身 401，说明 Refresh Token 已失效，跳转登录页
        localStorage.clear();
        window.location.href = '/login';
        return Promise.reject(error);
      }

      originalRequest._retry = true;

      if (isRefreshing) {
        // 防止并发请求重复发起续期，加入队列排队
        return new Promise((resolve, reject) => {
          failedQueue.push({ resolve, reject });
        })
          .then((token) => {
            originalRequest.headers.Authorization = `Bearer ${token}`;
            return api(originalRequest);
          })
          .catch((err) => Promise.reject(err));
      }

      isRefreshing = true;
      const refreshToken = localStorage.getItem('refresh_token');

      try {
        const { data } = await axios.post('/api/v1/auth/refresh', {
          refresh_token: refreshToken,
        });

        const newAccessToken = data.data.access_token;
        const newRefreshToken = data.data.refresh_token;

        localStorage.setItem('access_token', newAccessToken);
        localStorage.setItem('refresh_token', newRefreshToken);

        api.defaults.headers.common['Authorization'] = `Bearer ${newAccessToken}`;
        processQueue(null, newAccessToken);

        originalRequest.headers.Authorization = `Bearer ${newAccessToken}`;
        return api(originalRequest);
      } catch (refreshErr) {
        processQueue(refreshErr, null);
        localStorage.clear();
        window.location.href = '/login';
        return Promise.reject(refreshErr);
      } finally {
        isRefreshing = false;
      }
    }

    return Promise.reject(error);
  }
);
```
